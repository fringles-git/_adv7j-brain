# Accueil de l’Église adventiste de Troyes

Installer le dossier troyes comme thème WordPress sur une préproduction avec permaliens par nom de publication. L’activation crée les pages Première visite, Prière et Informations du site si leurs adresses sont disponibles. Si une page existe déjà, y ajouter le bloc Code court correspondant au type visite ou priere.

Dans Apparence → Éditeur → Modèles → Page d’accueil, les bénévoles peuvent modifier les textes, la carte horaire et les rencontres dans les blocs. Pour la photographie, sélectionner le groupe « arch » dans la vue en liste et y insérer une image WebP autorisée. Le motif de vitrail sert de visuel par défaut.

Avant ouverture publique, confirmer accès PMR, parking et dessertes, et compléter Informations du site avec éditeur, hébergeur, contact pour les droits et durée de conservation décidée par le comité. Dans wp-config.php, définir TROYES_VISITE_EMAIL et TROYES_PRIERE_EMAIL avec les adresses validées. Configurer la messagerie du site puis tester en préproduction la réception dans chaque boîte. Sans destinataire, le parcours propose l’accueil sur place. Exclure les pages de formulaire du cache HTML. Vérifier les services ajoutés par l’hébergeur ou d’autres extensions avant de décider du dispositif de consentement. Le thème utilise des polices locales et des liens externes, sans lecteur ni carte embarqués.

Polices Cormorant Garamond et Outfit, licences dans fonts/. Source éditoriale : rapport decision-2026-11-20 du dépôt et affiches locales, sans identifiants de réunion.
